# 配音生成与去杂音流水线

用户对杂音非常敏感，反复指出过：句间的吸气、开口前的“嗯/念”、嘴唇咔哒、句尾多出来的“免”声。**每一种都要扫、要清、要复查**，清理不能吃掉字头。

括号里是原作者项目里的脚本名（Python + numpy/soundfile + faster-whisper，ffmpeg）。脚本本身没有放进这个仓库；换环境时按下面的规则重写即可。

## 1. 生成

1. `reading-vNN.txt` 一句一行，整篇一次请求 MiniMax T2A（speech-2.8-hd，克隆音色，speed 1.2，开字幕）。
2. 用字幕 + 转写做逐字时间对齐（`align.py`）。MiniMax 常把几行合成一段字幕：按句末标点（。？！）拆回一行一句；不以句末标点结尾的片段（如“；”处断开的）先拼回去再拆（`split-lines.py`）。
3. 某句念错（多音字、符号、英文缩写）：只重新生成这一句，取出对应片段换进原配音，响度对齐，后面的时间顺延（`splice-line.py`）。

## 2. 清理（按顺序）

| 步骤 | 处理什么 | 规则 |
| --- | --- | --- |
| 母带（`vo-master.py`） | 响度 + 句内停顿 | 统一到 -16 LUFS / 真峰值 ≤ -1.5 dBTP。“，。？；：、”后的停顿里，吸气和“嗯”声（约 -33 dB、100–150 ms 的独立小包）压掉；保留下一字的清辅音字头（按“与元音相连、中间无低谷”找起点）；英文单词后的停顿不动；过响（> -26 dB）的不动 |
| 开头（`edge-scan.py --fix`） | 第一个字前的吸气 / 咔哒 | 静音 |
| 字头（`onset-clean.py`） | 字前的嘴唇咔哒、吸气 | 清掉，字头本身不动 |
| 句间（`gap-clean.py` + `line-cut.py`） | 两句之间 | **全部清成静音**，只留上一句约 60 ms 尾音和下一句约 30 ms 字头；s / sh / x 等清擦音开头的字多留一点，别把字吃掉 |
| 咔哒（`declick.py`） | 单个尖峰 | 只把那十几毫秒压低约 10 dB |
| 句尾（`tail-blip.py`） | 句尾多出来的短促“免/念”声 | 手工确认后静音（先看频谱，别把字的韵母当杂音） |
| 句首（`head-trim.py`） | 开口前 0.05–0.1 秒的“嗯/念” | 只剪响的部分 ≤ 150 ms 的短促杂声，第一个字的字头留着；超过上限的退回人工判断 |

**误伤就退回**：每一步之后比对每个字头的能量（`loss-scan.py`），损失落在字头 30 ms 以内、或被删的声音比 -34 dB 还响的位置，按时间段加入 skip 列表重跑（`mkskip.py` 自动生成）。每步之前备份 master（`previews/m0–m5-*.wav`）。

## 3. 切句

- 每句一个独立 wav，按 -55 dB 修掉首尾静音，相邻不重叠；两头 12 ms 淡入淡出。
- 文件名带内容哈希（`lNN-<hash>.wav`），旧文件自动删掉，避免 Studio 缓存旧配音。
- 用户在 Studio 剪过的句子读回 `line-trims.json`，不能冲掉。

## 4. 验收（每次改完都做）

| 检查 | 标准 |
| --- | --- |
| `click-scan.py` | 0 处 |
| `onset-clean` 复扫、`tail-blip.py` | 0 处 |
| `edge-scan.py` | 头尾静音 |
| `loss-scan.py` | 0 处字头损失 |
| `asr-compare.py` 逐句转写 | 清理后识别字数 ≥ 清理前；差异只能是同音字 / 繁体字 / 英文写法（如 ALEVO = A-Level） |
| `clip-asr.py` | 按时间轴实际播放的每一段再转写一遍 |
| 成片 | 响度约 -12.5 ~ -13 LUFS，峰值 ≤ -1.4 dBFS，不爆音 |

脚本通过不等于听感通过：无法试听时在 `STATUS.md` 里标“未试听”。
