# 数字人口播视频 — 制作规范

基准片：《爬藤指南-天文方向》v3（下称“藤校那条”）。这里没写到的细节，照它的做法，不另起一套。
画面风格可以每条不同、要“高级一点”；**配音和流程规范每条都照做**。

## 1. 项目结构

```
<项目>/
  BRIEF.md            需求、受众、画幅、配音参数、素材授权
  STATUS.md           每一轮改动：日期、用户原话、改了什么、怎么验证的
  script/
    script-vNN.txt    用户原稿（不改）
    reading-vNN.txt   朗读稿，一句一行
    line-trims.json   用户在 Studio 里剪过的配音（重建时读回）
    数字人交接.md
  assets/audio/       配音 mp3/master.wav/chartimes.json，lines/ 每句一个 wav
  assets/dh/          数字人片段、ref/ 同句配音
  assets/photos/      照片（记来源和授权）
  scripts/            build / cues / scenes / lib / fonts + 配音处理脚本
  previews/           备份、抽帧、检查结果
  renders/            成片
```

时间轴由 `cues.mjs`（每句、每个字的时间）驱动，`scenes.mjs` 写各幕画面，`build.mjs` 生成 `index.html`。

## 2. 配音（最重要）

- **音色**：MiniMax speech-2.8-hd，克隆音色（原作者 `Megan002`），**speed 1.2**。
- **文案**：用户口播稿原文不改，一句一行。整篇**一次请求**生成；MiniMax 把多行合成一段字幕时，按句末标点拆回一行一句。
- **母带**：-16 LUFS master；整片导出后检查响度和峰值（藤校成片 -12.5 LUFS / -1.4 dBFS，不能爆音）。
- **去杂音，一处都不能留**：流程和标准见 [配音去杂音.md](配音去杂音.md)。
- **念错字只修那一句**：例如“第一”念成“念第”、“A*”只念成“A”（改写成“A star”），只单独重新生成那一句，替换对应片段并对齐响度，后面的句子顺延，不重做整篇。
- **每句一个独立音频**：时间轴上一句一段，首尾修掉静音，相邻不重叠，两头 12 ms 淡入淡出；文件按内容哈希命名（避免 Studio 缓存旧配音）。
- **保留用户手剪**：用户在 Studio 里剪过的配音记在 `line-trims.json`，重建时从旧 `index.html` 读回，不能冲掉。用户手剪几句做示范时，按同样的规则剪其余的句子。
- **每次改完都要核对**：逐句转写，对比清理前后没有丢字。同音字、繁体字不算问题；误伤字头的句子退回不处理。
- **不加转场“嗖”声（whoosh）**。BGM 用 Inspired（Kevin MacLeod，CC BY 4.0），垫底约 -15.5 dB，**发布时简介署名**。

## 3. 数字人

- 一般 **7 镜**左右，放在各章节开头：**开场第 1 句全屏**，中间的用**画中画**，**结尾不用**。
- 先给用户交接单（台词、在成片里的时间、同句配音 mp3），用户拿**同一个克隆音色的同句配音**驱动口型。模板见 [数字人交接模板.md](数字人交接模板.md)。
- 画面要求：9:16、固定机位、腰部以上、头部在 y 450 以下、第 1 镜 y 1200–1620 留给字卡、片子里不带字幕。
- 片子回来后：转写 → 按句切开 → 对齐到时间轴 → 重建。
- **数字人那几句的声音**：用户已两次选择“用生成的配音”——片子按“片子说话长度 / 配音长度”匀速变速、去掉片子原声，这几句放清理后的配音。若用户选原声，则用原声并整体加速 1.15 倍。

## 4. 画面

- 1080×1920 竖屏，30fps，HyperFrames 制作。**不加字幕**，元素在说到那个词时才出现。
- 画面形式多样结合：满屏清晰照片 + 白字、虚化底的重点强调、信息卡、上图下文、数字人全屏或画中画；推屏转场。
- 满屏背景用竖图或 2400 px 高的大图，横图满屏会被放大 1.6–1.9 倍发虚。
- 安全区：版心 x 72–1008，顶部从 y≥118 开始，底部 250 px 不放关键内容；最小字号 ≥ 28 px；文字对比度要过 `hyperframes check`。
- 风格每条可以重新设计、追求高级感，参考 [风格参考/](../风格参考/)。

## 5. 封面

只占第 1 帧（第 2 帧即进正片），规范见 [风格参考/封面规范.md](../风格参考/封面规范.md)。

## 6. 结尾

最后一句是转化句，**只引导私信**（不放二维码、不引导其他平台）。

## 7. 预览、渲染、交付

1. `hyperframes check` 0 错误；逐幕末帧截图自查。
2. **完整预览给用户确认后再渲染**（`npx hyperframes@<版本> preview`）。
3. 按 delivery 画质渲染到 `renders/`，文件名用中文标题 + 版本号。
4. 渲完验收：ffprobe 核对规格、响度 / 峰值、抽帧看封面只在第 1 帧、转写开头几句复核。
5. 打开文件夹给用户；同时给发布简介里的 BGM 署名。
6. 每一轮改动记进 `STATUS.md`，写明用户原话和改了什么。
