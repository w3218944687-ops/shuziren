# 数字人交接单模板

配音和画面排好之后、渲染之前，把这张单子发给做数字人的人（`script/数字人交接.md`）。

---

# 数字人交接 — <视频标题>

全片 <秒数> 秒（按 <音色> 配音排好的时间轴）。数字人共 **N 镜**：第 1 镜全屏，其余画中画（右下角），结尾不用。其余画面已经做好。

| 镜头 | 句号 | 在成片里的位置 | 台词 | 同句配音 |
|---|---|---|---|---|
| 第 1 镜（全屏） | 1 | 0:00.0 – 0:07.4 | <第 1 句原文> | assets/dh/ref/dh01-line.mp3 |
| 第 2 镜（画中画） | 10 | 1:05.5 – 1:08.3 | <原文> | assets/dh/ref/dh10-line.mp3 |
| … | | | | |

（同句配音用的是去杂音后的版本。）

## 画面要求

- 竖屏 9:16（最好 1080×1920），固定机位，人物居中，腰部以上。
- 头部放在 y 450 以下。
- 第 1 镜下方 y 1200–1620 会压一张标题字卡，这一段别放重要的手势。
- 片子里不要带字幕或文字。
- 声音：用上面同句的配音驱动口型，和全片的声音保持一致。

## 交给我之后

发我 N 个 mp4（带原声），文件名写上句号（1.mp4、10.mp4……），或者一个视频按顺序连着说完 N 句也行。

---

## 片子回来后的处理

1. **转写 + 按句切开**（`dh-split.py <片子> <句号…>`）：一个视频连说多句时按转写找句界切开；横宽过大的重编码为 1440×1920。
2. **单句重对齐**（`dh-prep.py` / `dh-align.py`）：转写出繁体或漏字的句子单独重对齐。
3. **声音**：
   - 用生成的配音（用户常选）：片子按“说话长度 / 配音长度”匀速变速对齐（`dh-tts.py`），去掉原声，这几句放清理后的配音；
   - 用片子原声：整体 1.15 倍加速（`dh-speed.py`），时间轴按比例缩放。
4. **封面数字人卡**：从片子里挑睁眼、闭嘴、正对镜头的一帧，裁到胸部以上。
5. 重建 → 完整预览给用户确认 → 渲染。
