# 数字人口播视频制作规范

Megan 数字人口播视频（国际课程 / 升学规划科普，竖屏）的制作要求、流程与风格参考。
视频用 [HyperFrames](https://hyperframes.heygen.com)（HTML + GSAP）制作；配音用 MiniMax 克隆音色；数字人片段由用户另行生成后交回合成。

## 一句话原则

1. 配音是时间轴的基准，**杂音一处都不能留**，每次改完逐句转写核对不丢字。
2. 口播稿原文不改，一句一行；不加字幕，元素在说到时才出现。
3. 完整预览给用户确认后再渲染；每轮改动记进项目 `STATUS.md`（写明用户原话）。

文档中的本机路径已替换为 `<占位符>`，不含任何密钥，使用时按自己的环境填写。
