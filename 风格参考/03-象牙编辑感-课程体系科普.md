# 风格 03 — 象牙纸 · 海军蓝 · 哑金（A-Level 课程体系基础科普）

用户：“画面风格不用和以前完全一样，高级一点”。编辑 / 英伦学院感。约 4:12，37 句，7 镜数字人，21 幕，6 个章节。

## Palette

| 角色 | 值 | 用途 |
| --- | --- | --- |
| paper | `#FBF8F2`，顶部白色径向光 → `#F0E9DC` | 象牙纸底 |
| grain | 7px 点阵，墨色 5.5% | 细颗粒质感 |
| ink / navy | `#0E1624` / `#13213A` | 文字、深色卡 |
| gold / goldL | `#B08A45` / `#E3C98C` | 细线、编号、荧光底、照片上的强调字 |
| wine | `#7B1E2B` | 少量使用：删除线、警示 |
| slate | `#5E6675` | 次要文字、章节名 |

## Typography

- 标题：Noto Serif SC 900；正文：Noto Sans SC 700。
- 英文和数字：Playfair Display 700（编号、kicker 小字母间距 .3em）。
- 字体按实际用字子集化后存本地（均为 OFL）。

## 组件

- 页头：金色章节号 + 短金线 + 章节名 + 右侧“A-LEVEL GUIDE”。
- 标题下一条从左长出的金色渐变细线。
- 白色小圆角卡（10px）+ 柔和投影；深海军蓝卡带金色描边。
- 胶囊：描边 / 实心墨色 / 金色 / 半透明（照片上）。
- 照片上：上下渐变暗角 `.shade`，底部文字带 `.band`；白字 + 金色关键字 + 金色荧光底。

## 画面形式

满屏牛津 / 剑桥照片配白字、虚化照片的重点强调、白色信息卡（时间线、对比表、等级阶梯）、上图下文、数字人全屏（开场字卡在 y 1200–1620）和画中画。

## Motion

元素在说到的那个字入场（上移淡入 0.5s、弹出、金线展开、荧光笔扫底、删除线）；推屏转场；只用很轻的 click / pop / ping，不加 whoosh。BGM Inspired，-15.5 dB。
