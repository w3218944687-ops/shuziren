# 封面规范

封面**只占第 1 帧**，第 2 帧即进正片。

| 元素 | 要求 |
| --- | --- |
| 底 | 米白点阵底（可加一团很淡的暖红光晕） |
| 关键词 | 红色超大字（如 `#C8281E`），一两个词：“藤校”“A-Level” |
| 大标题 | 深色粗衬线大字，关键行加**黄色荧光底**（如 `#FFD640`） |
| 副标题 | 灰色，一行；内容多时可以不要 |
| 标签 | 1–2 个胶囊标签；用户说过“不要这么多小字，突出重点”时只留大字 |
| 数字人卡 | **角落**放一帧数字人：睁眼、闭嘴、正对镜头，裁到胸部以上，白边圆角 + 柔和投影 |

- 标题用中文，**不用英文缩写**（写“藤校”，不写 IVY）；课程名本身是英文的（A-Level）可以保留。
- 数字人卡取本条片子里的一帧；片子没回来前可借上一条的，回来后必须换。
