# 风格 02 — 浅蓝网格 + 专业卡片（A-Level 选课指南·10 个专业）

按用户给的参考视频做的卡片版式（“照参考卡片做”）。约 2:05，24 句，2 镜数字人。

## Palette

| 角色 | 值 | 用途 |
| --- | --- | --- |
| bg | `#F3F6FB` + 细网格 | 全片底 |
| ink | `#16213E` | 标题、正文 |
| blue | `#2F5FD0` | 编号、必选、主色 |
| orange / peach | `#C95A1C` / `#FDEFE5` | “WHY / 为什么”框 |
| gray | `#7A869C` | 英文、次要信息 |

## 版式

- 每个专业一张卡（两句一张）：中文大标题 + 英文 + 线条图标；必选 / 推荐 / 可选三行时间线；科目胶囊带英文；橙色“为什么”框；大号淡色编号（Georgia，7% 透明度，装饰）；进度条。
- 科目在说到时弹出。
- 去掉了藤校那条的顶部章节栏和闪白层。

红色“A-Level”+ 黄底“10个专业”+“选课组合”三行大字 + 数字人卡（用户：“不要这么多小字，突出重点”）。见 [封面样例/cover-alevel-subject.png](封面样例/cover-alevel-subject.png)。
