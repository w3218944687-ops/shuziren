# 风格 01 — 米白纸本 + 满屏照片（爬藤指南·天文方向 v3）

基准片，配音和流程规范都以它为准。约 3:50，45 句，7 镜数字人。

## Palette

| 角色 | 值 | 用途 |
| --- | --- | --- |
| paper | `#F7F2EA` | 纸本底 |
| ink / body / gray | `#1C1915` / `#3B342D` / `#8A8178` | 文字三级 |
| acc（学院蓝） | `#1F3C78` | 核心信息 |
| maroon / red | `#9E2A23` / `#C8322A` | 强调、红叉、关键词 |
| green | `#2E7D5B` | 对勾 |
| amber / 黄 | `#E8A317` / `#FFD54A` | 照片上的高亮字、下划线、标签 |
| 暗底 | `#101626` | 照片底、虚化底的海军蓝罩色 |

## 画面形式

- `photoBg`：满屏清晰照片（竖图或大图）+ 白字，顶部自带暗角。
- `blurBg navy`：虚化照片 + 海军蓝罩，用于重点强调；`blurBg dim`：信息卡。
- `splitBg`：上图下文。
- 页头：一行白字标题 + 玻璃章节栏（黄色指示）。
- 数字人：`dhFull` 全屏 + 胸前字卡；`pip` 画中画，白边 6px、圆角 30px、深投影，结束前 0.5 秒先淡出。
- 小物件：代码窗、虚线票据、印章、红叉、下划线。

## Motion

- 推屏转场，**不加 whoosh**；元素在说到的那个字入场（上移淡入、弹出、划线、荧光笔）。
- 音效只用很轻的 click / pop。
